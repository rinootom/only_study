목적	명령어
Git 설치 확인	git --version
사용자 이름 설정	git config --global user.name "이름"
이메일 설정	git config --global user.email "이메일"
프로젝트 폴더 이동	Set-Location "C:\Users\user\source\repos\WindowsFormsApp1"
상태 확인	git status
Git 초기화 (최초 1회)	git init
브랜치 이름 설정	git branch -M main
git switch fetch

원격 저장소 확인	git remote -v
원격 저장소 연결 (최초 1회)	git remote add origin https://gitlab.com/rinotom/poc_project.git
파일 추가	git add .
커밋	git commit -m "수정 내용"
최초 업로드	git push -u origin main
